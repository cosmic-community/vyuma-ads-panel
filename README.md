# Vyuma Ads Panel - Professional Advertising Platform

![Vyuma Ads Platform](https://images.unsplash.com/photo-1460925895917-afdab827c52f?w=1200&h=300&fit=crop&auto=format,compress)

A comprehensive advertising management platform built with Next.js and Cosmic CMS, providing Facebook Ads Manager-like functionality with a dual-interface system for advertisers and platform administrators.

## ✨ Features

### For Advertisers
- 📊 **Campaign Management** - Create, manage, and optimize advertising campaigns
- 🎯 **Advanced Targeting** - Precise audience selection with demographics, interests, and behaviors
- 📈 **Real-time Analytics** - Live performance metrics and comprehensive reporting
- 💰 **Budget Control** - Flexible budget options with automated bidding strategies
- 📱 **Multiple Ad Formats** - Support for image, video, carousel, and story ads

### For Administrators
- 🏠 **Admin Dashboard** - Platform health metrics and system overview
- ✅ **Ad Review System** - Automated and manual ad approval workflows
- 👥 **User Management** - Complete user administration and activity tracking
- 💳 **Financial Management** - Revenue tracking, payouts, and invoice generation
- ⚙️ **Platform Configuration** - Manage policies, pricing, and system settings

## Technical Features
- 🔐 **Secure Authentication** - Role-based access control with session management
- 🚀 **Real-time Updates** - Live data synchronization across all interfaces
- 📱 **Responsive Design** - Optimized for desktop and mobile devices
- 🔧 **API Integration** - RESTful APIs for external integrations
- 📊 **Advanced Analytics** - Comprehensive reporting with export capabilities

## 📦 Getting Started

### Prerequisites

- Node.js 18+ or Bun runtime
- Cosmic CMS bucket with appropriate content models
- Environment variables configured

### Installation

1. Clone the repository
```bash
git clone <repository-url>
cd vyuma-ads-panel
```

2. Install dependencies
```bash
bun install
```

3. Set up environment variables
```bash
# Create .env.local file
COSMIC_BUCKET_SLUG=your-bucket-slug
COSMIC_READ_KEY=your-read-key
COSMIC_WRITE_KEY=your-write-key
JWT_SECRET=your-jwt-secret-minimum-32-characters
```

4. Run the development server
```bash
bun dev
```

5. Open [http://localhost:3000](http://localhost:3000) in your browser

## 🚀 Cosmic SDK Examples

### Fetching Campaigns
```typescript
const campaigns = await cosmic.objects
  .find({ type: 'campaigns' })
  .props(['title', 'slug', 'metadata'])
  .depth(1);
```

### Creating a New Campaign
```typescript
await cosmic.objects.insertOne({
  title: 'Summer Sale Campaign',
  type: 'campaigns',
  metadata: {
    status: 'draft',
    budget_type: 'daily',
    daily_budget: 100,
    objective: 'conversions'
  }
});
```

### Updating Campaign Status
```typescript
await cosmic.objects.updateOne(campaignId, {
  metadata: {
    status: 'active'
  }
});
```

## 🌐 Cosmic CMS Integration

This application uses Cosmic CMS to manage:
- **Users & Authentication** - User profiles and credentials
- **Campaigns** - Complete campaign data and settings
- **Ads** - Ad creatives, formats, and configurations
- **Analytics** - Performance metrics and reporting data
- **Billing** - Payment methods and transaction history
- **Settings** - Platform configuration and policies

Content models are designed to support complex relationships between campaigns, ads, audiences, and analytics data.
